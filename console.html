Log in with GitHub

Change the site without touching code. Log on with your GitHub key once and the console remembers it on this device.

Leave blank and the console will try to find it.

First time? How to get your GitHub key
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens and press Generate new token.
  2. Give it a name like “Harry console”, and pick an expiry.
  3. Under Repository access choose Only select repositories and pick your site's repository.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Press Generate token, copy it (it starts with github_pat_) and paste it above.

How the trivia desk works

Days are built ahead from the question bank. A GitHub Action builds more and refreshes rarity every Monday, and you can do it here too.

Nothing repeats within 730 days. Swapping a question takes an unused one from the bank. When you swap, it asks whether to retire the old one: say yes if it was wrong, so it never comes back.

Top-up pack: a readable text file with every question and when it was used, plus a ready-made request. Paste it into a chat with Claude, then paste the reply into Import questions.

Play-test opens the day in a new tab exactly as you've edited it, without saving anything.

The files in the repository are encoded so answers can't be read at a glance. This desk is the readable view.
