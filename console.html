Log in with GitHub

Your changes are committed straight to the repository that hosts this site. GitHub Pages republishes in about a minute.

How do I get a token?
  1. On GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under Repository access choose Only select repositories and pick this site's repository.
  3. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
  4. Copy the token (it starts with github_pat_) and paste it above. It is only sent to api.github.com.
